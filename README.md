# Basic_ATM_System
To design and implement an ATM system using Python that allows users to perform basic banking operations such as checking account balance, withdrawing money, depositing money, and exiting the system using a menu-driven approach.
This project simulates the working of an Automated Teller Machine (ATM).
The user interacts with the system through a menu-driven interface.
The system allows the user to check the current balance, deposit money, withdraw money, or
exit the program.
The account balance is updated after every successful transaction.
